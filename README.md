# FUTURE_PE_03 — AI SEO Blog & Content Cluster Generator

## Task Overview

This project is part of the Future Interns Prompt Engineering Internship.

The objective of Task 3 is to create an AI-powered prompt system that generates SEO-optimized blog content and strategic content clusters for business websites.

## Project Goals

- Generate SEO-friendly blog outlines
- Create long-form SEO blog posts
- Map content to search intent
- Generate content clusters
- Suggest internal linking opportunities
- Improve local SEO targeting
- Build topical authority
- Create useful and readable business-focused content

## Prompt System

The project contains three main prompts:

### Prompt 1 — SEO Blog Outline Generator

Generates a structured SEO blog outline using H1, H2, and H3 headings while considering keywords, search intent, local SEO, internal linking, and business goals.

### Prompt 2 — Long-Form SEO Blog Generator

Uses the SEO outline to generate a complete long-form blog post with an SEO title, meta description, URL slug, headings, useful content, local SEO references, CTA, and internal linking suggestions.

### Prompt 3 — Content Cluster & Internal Linking Generator

Creates a pillar page and supporting cluster topics based on the main keyword. It also provides an internal linking strategy and explains how the content pieces build topical authority.

## Outputs

The project includes:

- `seo_blog_outline.md` — SEO blog outline
- `seo_blog.md` — Complete long-form SEO blog
- `content_cluster.md` — Content cluster and internal linking strategy
